# Legacy Streamlit prototype

The first hackathon prototype. It is **not used by the current dashboard or the Docker
deployment**; it stays as migration reference. The live UI is `frontend/` (React).

It runs on mock JSON (`data/mock/`) through `kizuna/api.py`, and can switch to the real FastAPI
backend (`KIZUNA_FRONTEND_MODE`, `KIZUNA_API_URL`).

```
streamlit_app.py  entry point, page navigation (not named app.py: that would shadow the backend `app` package)
views/        one module per page (portfolio, new_analysis, results, scenario_lab, ...)
sections/     tabs of the results page
kizuna/       api client (mock + backend), scoring engine, charts, state, theme
data/mock/    mock backend responses, generated by scripts/make_mock_data.py
data/geo/     India states GeoJSON used by the map
tests/        engine, mock-data, page-render and backend-adapter tests
```

## Run

Run from this folder: Streamlit reads `.streamlit/config.toml` from the working directory.

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
pytest
```

`pytest` pins `KIZUNA_FRONTEND_MODE=mock` so results do not depend on an API running on port 8000.
